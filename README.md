# Projetos Acadêmicos

Repositório com os projetos desenvolvidos ao longo da faculdade.

## Projetos

| Projeto | Linguagem | Descrição |
|---|---|---|
| [calculadora-polinomios](./calculadora-polinomios) | C | Calculadora de polinômios: exibe, calcula valor numérico, soma e multiplica polinômios via menu interativo |
| [lab-recursao-busca](./lab-recursao-busca) | C | Laboratório de funções recursivas: busca binária, potência, busca linear, menor elemento e soma de sequência |
| [poo-veiculos](./poo-veiculos) | Java | Exercício de POO com herança: classe base Veiculo e subclasses Carro, Caminhao e Moto |
| [dicionario-palavras](./dicionario-palavras) | C | Dicionário de palavras com busca binária recursiva, inserção ordenada e filtro de stop words |

## Como usar

Cada pasta contém um projeto independente com seu próprio README explicando como compilar e executar.
